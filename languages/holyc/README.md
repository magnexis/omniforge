# HolyC

This language is catalogued in Omniforge but is not counted as a supported worker yet.

## Status

- Support tier: `Tier 0`
- Runtime: `TempleOS-hosted HolyC`
- Worker status: `not counted`
- Admission rule: practical execution path, OFP worker, verified coordinator execution path, and automated tests

## Notes

HolyC is strongly tied to TempleOS. Omniforge tracks it as a catalogued historical/custom language until there is a realistic host, VM, or emulator-backed execution path.
