# Roadmap

## Phase 1: Foundation

- preserve current Omniforge core
- document language roles
- formalize incident lifecycle
- formalize repair policy
- formalize protocol evolution
- harden CLI and toolchain detection

## Phase 2: First Reliability Loop

- detect a controlled build failure
- create a structured incident
- route to a build failure worker
- produce a repair proposal
- verify the repair
- record the result

## Phase 3: Polyglot Reliability Expansion

- add worker families by operational purpose
- add evidence and repair schemas
- add worker health supervision
- add rollback flow

## Phase 4: Learning and Evaluation

- incident fingerprints
- worker scoring
- repair ranking
- reproducible incident arena

## Phase 5: Distribution

- daemon packaging
- API
- desktop agent
- GitHub Action
- containerized language packs
